# General Access Policy
**Project:** Alpha
**Effective Date:** January 1, 2024

## 1. Authentication
All data engineers working on Project Alpha must use Multi-Factor Authentication (MFA) to access the production SQLite database. 
Passwords must be at least 16 characters long and rotated every 90 days.

## 2. Remote Access
Accessing the compute engines from outside the corporate network requires a secure VPN connection. No direct SSH access is permitted from public IP addresses under any circumstances.
